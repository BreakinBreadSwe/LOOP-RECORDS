# Loop Records — notes for Claude

Swedish house/techno label, Stockholm 1993–1998 (Discogs label 179847, sublabel Plumphouse).
Owner works on Breakin Bread (`BreakinBreadSwe/bb-native`, Next.js + Firestore); Loop's data
must always be sendable to Breakin Bread with one click.

- Source files: `src/app.template.html` (public site), `src/admin.js` (back office, spliced in at
  `/*__ADMIN__*/`), `src/runtime.js` (Supabase implementation of the small `window.claude` API the
  page uses). `public/index.html` is generated by `npm run build`; never edit it.
- Back-office records live in Supabase `app_docs` (collection, id, data jsonb). Collections:
  products, orders, events, sync, rights, artwork, settings.
- `lib/bundle.js` is the contract with Breakin Bread (schema `loop-records.breakinbread/v1`).
  If you change its shape, update `bb-native/src/lib/label-import.ts` in the same change and keep
  ids stable (`loop-<discogsId>`, `loop-<artistKey>`, `loop-yt-<youtubeId>`).
- Never send customer contact details or licensee contacts to Breakin Bread.
- Before committing: `npm test && npm run build`.
